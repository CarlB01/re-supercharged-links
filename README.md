A modernized, highly optimized, and decoupled fork of the original *Supercharged Links* plugin for Obsidian. This version is independently maintained and rebuilt from scratch to leverage modern Obsidian paradigms, eliminate memory leaks, and guarantee fluid performance on both Desktop and mobile iOS/Android devices.

---

## 📦 Installation Instructions

### Method 1: Via Obsidian BRAT (Recommended for Beta/Updates)
Until the plugin is officially approved in the Obsidian Community Plugin marketplace, the easiest way to install and receive automatic updates is via the **BRAT** plugin:

1. Open Obsidian **Settings** and navigate to **Community Plugins**.
2. Search for **BRAT** (Obsidian 42 - BRAT) and click **Install**, then **Enable**.
3. Go to the BRAT plugin settings panel.
4. Click on **Add Beta Plugin** under the *Beta Plugin List*.
5. Paste the repository URL: `https://github.com`
6. Click **Add Plugin**. BRAT will automatically download, compile, and enable **Re-Supercharged Links** v0.0.15.

### Method 2: Manual Installation
1. Navigate to the [Releases](https://github.com/releases) page of this repository.
2. Download the latest asset bundle containing `main.js`, `styles.css`, and `manifest.json`.
3. Open your Obsidian Vault's local directory and locate `.obsidian/plugins/` (create the `plugins` folder if it doesn't exist).
4. Create a new folder named `re-supercharged-links`.
5. Drop the three downloaded files directly into that folder.
6. Reload Obsidian, go to **Community Plugins**, and turn on **Re-Supercharged Links**.

## 🏗️ Core Architectural Blueprint (v0.0.15)

The v0.0.15 framework shifts the plugin from heavy DOM scanning to a lightweight, reactive data ecosystem, optimizing the settings engine, dynamic event scavenging for metadata, UI state handling, and CSS infrastructure.

## 📊 Comprehensive Efficiency Assessment

* **Memory Optimization:** Fixed legacy memory leaks through an advanced Event Delegation system.
* **Fluid Mobile Editing:** Features an isolated mobile layout stylesheet and silent data committing for smooth iOS/Android UX.
* **Visual Form Symmetries:** Uses distinct icons (🟢 and ⏹️) matching modern design frameworks.
